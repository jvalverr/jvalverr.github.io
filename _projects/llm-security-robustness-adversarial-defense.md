### Project details

- **Role:** Research Collaborator
- **Institutions:** University of Campinas (Brazil), Tecnologico de Monterrey (Mexico), George Mason University (USA)
- **Period:** 2024–2027

### Overview

Large Language Models are increasingly integrated into enterprise applications,
AI assistants, software engineering tools, Retrieval-Augmented Generation
systems and agentic workflows.

These architectures introduce a new security surface in which natural language
can act both as data and as a control mechanism. Malicious or manipulated
content may attempt to alter system behavior through prompt injection,
jailbreaks, indirect instructions or other adversarial interactions.

This research project investigates methods for improving the **security,
robustness and reliability of LLM-integrated systems**, with particular
attention to defenses that can operate independently of the underlying model
and remain effective across different applications, domains and attack
strategies.

### Research questions

The project explores questions such as:

- How can prompt-injection and jailbreak attempts be detected and mitigated?
- How reliably do LLM security mechanisms generalize across domains and prompt distributions?
- How can guardrails balance attack detection with legitimate user interactions?
- How should security mechanisms be evaluated under realistic adversarial conditions?
- How can LLM-based agents and RAG systems be protected against indirect manipulation?
- How can security controls remain auditable, efficient and model-independent?

### Current research direction

The project currently focuses on **prompt-injection defense, adversarial
robustness and model-independent guardrails for LLM-integrated systems**.

The research is expanding toward **multilingual attacks, indirect prompt
injection, agentic systems, RAG security and adaptive defense mechanisms**.

### Research outputs

- **AETHON:** a lightweight, model-agnostic pre-inference security middleware
  designed to evaluate potentially adversarial prompts before they reach the
  target LLM.
